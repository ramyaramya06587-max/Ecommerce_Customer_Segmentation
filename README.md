# E-Commerce Customer Segmentation & Product Recommendation

## Project Overview
This project analyzes e-commerce customer purchasing behavior using RFM analysis, K-Means clustering, and Cosine Similarity to identify customer segments and recommend similar product categories.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Workflow
1. Data loading and cleaning
2. RFM analysis
3. Feature scaling
4. Elbow Method
5. K-Means customer segmentation
6. Customer cluster visualization
7. Product recommendations using Cosine Similarity
8. Business recommendations

## Dataset
E-Commerce Customer Behavior Dataset.

## Outputs
- Cleaned transaction data
- Customer segments
- Product similarity results
- Business recommendations
- Customer segmentation visualization

## How to Run
1. Install the required libraries.
2. Place the dataset inside the `data` folder.
3. Open the Jupyter Notebook.
4. Run all cells.

## Objective
To understand customer purchasing patterns, segment customers, and support data-driven business decisions.
